## Conventions

**Branches** follow conventional commits with path-based scoping:

```
type/scope-description              # root branch
_type/scope-description/sub-task    # child (merges into parent)
__type/.../sub-sub-task             # grandchild
```

Types: `fix/` `feat/` `chore/` `hotfix/` `refactor/` `spike/`

**Commits**: `type(scope): description` — [conventional commits](https://www.conventionalcommits.org)

**Package manager**: `pnpm` — do not use `npm`
